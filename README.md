# ☕ Coffee Shop Sale Dashboard (Excel Project)

An interactive Excel dashboard designed to visualize and analyze coffee shop sales data. This project helps managers and stakeholders monitor daily performance, product-wise trends, and customer preferences using intuitive visuals and slicers.

---

## 🧾 Overview

This Excel-based dashboard provides:

- Daily and monthly sales trends
- Product-wise and category-wise sales breakdown
- Insights into top-selling items
- Visual indicators using KPIs, charts, and slicers

The dashboard enables data-driven decisions to optimize product offerings, manage inventory, and improve overall business performance.

---

## 💡 Skills Demonstrated

- Excel Dashboard Design  
- Pivot Tables & Charts  
- Data Cleaning & Transformation  
- Slicers & Interactive Filtering  
- KPI Metrics with Conditional Formatting  
- Visual Storytelling with Data
